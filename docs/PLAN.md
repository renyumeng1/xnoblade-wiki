## P1 · 用户点名的三个痛点

### 1. 任务要能在地图上一一步步走

- [x] `Planner.anchor()` 六级定位：内链地点 > 同地区地名最长匹配 > 全局地名兜底 > 敌人刷新点 > 采集点 > NPC 出现坐标 > 放弃。
- [x] 生成计划时把每一步写成 `plan_step`，带 `map_id + fx + fy`，地图上按序号连线。
- [x] **跨区域任务全局地名兜底**：`quest_location` 只记接取地，像「名流帽」接取在英维迪亚、后续步骤跑到
      阿伐利缇亚市场，只在该地区地名池里找必然失败。现在同地区匹配落空后再用全库地名试一次
      （`Gazetteer.matchPlaces(step.text, null, 1)`），`tools/anchoring_stats.py` 同步复刻。
- [x] **NPC 出现坐标定位**：`npc_game_appearance.x/z` 与 `frontiernav_map_marker.frontier_x/y` 同尺度
      （古拉·托里格镇 NPC x∈[-174,164]，同图 frontier_x 同区间），可直接当平面坐标用；
      只收 `JOIN map m ON m.name = g.game_map` 能连上的行，黄金之国 DLC 的 NPC（`game_map` 为空）自然被过滤。
      名字按长度降序匹配，「阿尔巴」不会命中「阿尔巴马格」；有地区提示时只接受同地区。实测新增 12 步命中。
- [x] **图级定位档**：同任务多数已定位步骤落在哪张图，剩下没坐标的步骤就记 `mapOnly = map_id`
      （只到图、无坐标），UI 上单独标「图级定位」。统计：1,232 步里精确 867（70.4%）/ 图级 178（14.4%）/
      未定位 187（15.2%，其中 180 步是黄金之国 DLC）。
- [x] **三档 UI**：任务详情统计「N 步，X 步已定位 · Y 步可到图」，计划页副标题「X 步已定位 · Y 步仅到图」；
      步骤行分别显示「地图 · X」「地图 · X（无坐标）」「未定位」，图级步骤也能一键进对应地图。
- [x] **长按地图钉点**：`MapCanvas.onLongPressAt` 把屏幕坐标逆变换回 frontier 坐标，弹窗可
  - 新建一个自定义步骤，或
  - **绑定到当前计划里还没定位的步骤**（`PlanStore.setStepPoint`）。
- [x] 计划详情「看地图」跳到该步骤所在图（没有坐标的步骤退到第一个有 `map_id` 的步骤）。
- [x] **逐段导航**（`plan/RouteGuide.kt`）：把 `RouteGraph` 折线按有名地标切成 leg，地图页「逐段导航 N/M」卡片
      显示方位 / 距离 / 转向，当前段金色加粗高亮，`‹ ›` 切段；计划页每个已定位步骤追加
      「路线：从第 N 步过来 西北 约 67 · 经 X · 2 段」，坐标重合写「与第 N 步是同一位置」，跳过的无坐标步骤报数量。
      停靠点只认 `notable` 点，合成端点与 `#数字` 编号名排除：修前同一条路线 24 段（含 `Door Point #85`），修后 11 段。
      实机证据见 `README.md`「验证」。

### 2. 异刃开环要明确

- [x] 每个节点按等级列出 `requirement / effect / achievement_count`，可勾选本地进度。
- [x] 开环计划只列未习得等级，需求里的地名/敌名自动找点。
- [x] **定位链重写**（`Planner.buildBladePlan`）：
      地点内链 > 同地区地名 > 全局地名 > NPC > 敌人（整串 + 「XX 族」族名）> 采集品 > 地区主图（图级）。
      - `Gazetteer.matchRegion()`：先全长匹配 `map.display_name`，再拿地区名前 3~8 字匹配简称，
        全长优先（「莫尔斯断崖」不会被「莫尔斯之地」抢走）。
      - `Gazetteer.matchEnemyFamily()`：需求含「族」时取「族」前那段切词，取最后一段，
        并确认库里确有敌人名包含它才用（如「…以外的甲狼兽族」→「甲狼兽」）。
      - 敌人刷新点只在**同地区**里选；只在别处刷的不钉点，detail 写
        「提示：这个敌人的刷新点实际在 X，与需求地区（Y）不符」。
      - 只写地区的需求落到该地区 `marker_count` 最大的图（`regionMainMap()`，图级、无坐标）。
      - 26 条「怎么刷」模板（按 key 长度降序匹配），纯战斗/计数需求不再是干巴巴一句计数。
- [x] **离线统计** `tools/blade_anchoring.py`（old/new 两套逻辑对照）：
      2,372 条需求里 444 条是「初始习得」（计划跳过），进入计划的 1,928 条可定位 372 → 433
      （19.3% → 22.5%），敌人族 +13、NPC +1、图级 +48；
      「旧逻辑钉上、新逻辑没钉上」= 0 条（无回归，脚本内置检查）。焰：36 步计划 5 → 6 步已定位。
- [ ] 解析需求模板提升落点率：`在<地区>打倒<N>只<敌人>`、`使用<技能> <N> 次`、`采集<N>个<物品>`
      —— 本轮改了「找点」而不是「拆模板」；Collect 仍 50%，Gimmick 仍 59%。
- [ ] 开环计划分组：按「对话 / 战斗 / 采集 / 场景」分类折叠，长列表更好读。
- [ ] 族名表：库里没有「族 → 刷新点」映射，现在是按敌人名包含推断（13 条）。
      要做准，需要补一份族名/变异体表，属数据侧工作。

### 3. 接入 Agent 做规划

- [x] OpenAI 兼容 `/chat/completions` + `tool_calls` 循环（≤8 轮），失败回退离线规则。
- [x] 17 个受限工具：搜索任务/物品/敌人、查任务步骤、查开环需求、查地图点位、查采集点、估算同图路线、读写计划。
- [x] 聊天里识别 `#N` 直接跳计划详情。
- [x] 助手页 UI 端到端实测（模拟器 + grok-4.7 真端点）：工具行、多轮上下文、`#N` / `plan_id=N` 都能跳计划。
- [x] 允许 `http://` 明文端点（`AndroidManifest` 开 `usesCleartextTraffic`）。此前局域网端点会被系统直接拦掉，
      表现为「请求失败：Cleartext HTTP traffic ... not permitted；已回退到离线规划」。
- [x] 回答里的 Markdown 降级渲染（`**粗体**`、行内代码、`#` 标题、`- ` 列表），不再把 `**` 和反引号露给用户。
- [x] 工具结果超长改为 `{"truncated": true, "preview": ...}` 信封；`get_blade` 补 `node_count` / `omitted_nodes`，
      修掉 2,600 字符硬截断导致模型回答「后半被截断」的问题（上限提到 6,000）。
- [x] 未配置端点时完全离线，不发网络请求。
- [x] 模型名可留空：请求体不带 `model`。注意「可空」只是协议层允许，端点不一定接受——
  实测自建中转端点留空返回 `HTTP 400 Field 'model' is required`，已改成可操作提示（填模型名后重试）。
- [ ] 流式输出（现在是一次性返回，长回答会等）。
- [ ] 让 Agent 记住「当前正在看的任务/地图」作为上下文。

## P2 · 体验补强

- [x] 设置页状态即时刷新：清空/保存后标题、连接 Tag、提示文案同帧更新。
      此前这两处读 `SharedPreferences`（非可观察），Compose 的细粒度重组会跳过它们，
      出现「字段已清空、提示已写离线，头部仍显示已连接」；改为从 `baseUrl / apiKey` 推导。

- [ ] 计划详情顶部「看地图」目前只打开第一个 pin，改成按 `map_id` 分 Tab。
- [x] 采集步骤接 `collection_drop` / `collection_marker`：Collect 落点 32% → 50%（77/155）。
- [x] 路线规划：`RouteGraph` 用同图点位 kNN + `route_access_point` 电梯/传送点建图跑 Dijkstra，
      地图上叠加折线；`tools/route_stats.py` 采样 1,412 对，绕行比 p50 1.06 / p90 1.43，0 对不连通。
      仍然不是真实路网，UI 与 Agent 都标注「估算」。
- [x] Agent 工具补 `collect_spots`、`route_between`（共 17 个）。
- [x] `find_place` 支持「地区 + 的 + 地名」拆词匹配与区域名兜底（返回 `maps`，不带坐标）。
- [x] 真实模型探针 `tools/llm_probe.py`：grok-4.7 实测 5/5（同图路线、采集、空结果、跨图、未收录物品）。
- [ ] 地图离线包：现在 80 张 PNG 共 37 MB（已按长边 2560 下采样解码，避免 59 MB/张的解码峰值）。
- [ ] 深色/浅色切换（现在强制深色，因为游戏 UI 与地图对比度）。
