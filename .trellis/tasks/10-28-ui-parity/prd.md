# 功能对齐原版 1.2.2 + 视觉自研

父任务 `10-28-replica-1.2.2/prd.md` 已把本任务定为第一阶段。下面的「现状」是建任务时的基线，当前工作区已经部分改过，以父任务 `design.md` 第 3 节为准。

## Goal

功能上对齐原版 1.2.2（`cn.xenoblade2.wiki`）：页面、交互、数据展示能一一对上，可以手测。

视觉上**不能**对齐原版。配色、卡片结构、图标风格、排版节奏都要自成一套，避免抄袭争议。判定标准是父任务 `prd.md` 的 Acceptance Criteria 第 2 条。

## 现状

- `ui/theme/Theme.kt`：硬编码深色 + 青色系，与原版浅色配色不是一套。
- `ui/App.kt:136`：底部 tab 为 首页/任务/异刃/地图/计划（固定 5 个）。
- `ui/screens/HomeScreen.kt`：统计卡 + 4 宫格 + 进行中计划。
- `ui/screens/BladeScreens.kt`：小圆头像列表。
- `ui/screens/QuestScreens.kt`：扁平列表 + chip。

## Requirements

1. **配色**：`Palette` 拆浅/深两套，取值为父任务 `design.md` 第 8.2 节的自研配色（**不是**第 2.1 节的原版取值）；默认浅色，设置页可选「跟随系统 / 浅色 / 深色」。
2. **图鉴**：搜索框 + 四个内嵌分组，覆盖原版 20 个功能。中文做行标题。无数据进占位页。
3. **底部导航**：固定 4 项 = 图鉴 / 地图 / 记录 / 设置。设置可置顶最多 3 个图鉴入口，不复制原版 5 tab 编辑器。
4. **异刃页**：大立绘网格 + 多选收集 + 全部/已收集/未收集 + 属性 chip + 补正 chip。
5. **任务页**：四大类卡片（普通 / 异刃 / 佣兵团 / 非正式），进入后各自列表。
6. **怪物页**：搜索 + 收集筛选 + 地区 chip + 普通/珍稀种 chip + 分组列表。
7. **设置页**：Tab 设置 / 外观 / 内容偏好 / 关于（不复制原版的友盟、更新检查、隐私弹窗）。
8. **保留能力、不占首页**：Agent 入口留在设置页，「进行中计划」留在素材规划入口。首页只放搜索、20 卡片和浮动操作区。

## Acceptance Criteria

- [ ] 首页与原版并排比对：入口数量、顺序、文案一致（布局和视觉不要求一致）
- [ ] 底部为图鉴 / 地图 / 记录 / 设置；置顶入口重启后仍在
- [ ] 异刃页能看到大立绘与属性/补正筛选，不再是小圆头像
- [ ] 任务页四大类可分别进入，计数正确
- [ ] 浅色/深色切换后无对比度问题（重点检查地图页与 Agent 页）
- [ ] 未收录模块有明确占位说明，不出现空白页或崩溃

## Constraints

- 文案可对齐，但**不复制**原版代码/资源/视觉资产；布局用现有 Compose 体系重写。
- 原版 Titan 插画、marker 位图、物品分类图标不进 `app/`。
- 不引入新 UI 框架；不接统计 SDK。
- 改动集中 `ui/theme/`、`ui/App.kt`、`ui/screens/*`、`ui/components/`。

## Known Gaps

- 原版 20 个入口中，Mercenary Training / Field Skills / Drivers / Weapons / Weather / Shops / Heart-to-Hearts / Poppi Parts / Challenge Battles 等，我方数据库是否有对应表需逐一核对；缺表的先占位。

## Notes

- 建议分两批：**批 A**（主题 + 首页 + tab + 设置）、**批 B**（异刃/任务/怪物页重做），每批单独编译安装给用户手测。
- 依赖 `10-28-icons-markers` 提供图标，避免做完布局又返工。
