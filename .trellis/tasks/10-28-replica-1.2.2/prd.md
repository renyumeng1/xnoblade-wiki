# 复刻原版 1.2.2 UI/功能 + 路线规划 + 开环 + Agent

## Goal

以 Gitee 发布的原版 APK 1.2.2（包名 `cn.xenoblade2.wiki`）为对照，把「异度神剑 2 Wiki」安卓端的功能与 UI 复刻到本项目（`cn.xenoblade2.next`），并在复刻基础上做三项增强：

1. 地图上的任务规划要能一步步走（传送点 → 路径 → 目标点，含分层地图）
2. 异刃开环任务说得更明确（每个节点缺什么、去哪拿）
3. 接入 Agent / 大模型，用 App 内数据做规划与问答

## Background

- 原版未开源，只能通过 APK 反编译（`src/jadx/`）与实机截图做 clean-room 对照。
- 本项目已具备：514 任务 / 1232 可拆步骤 / 55 异刃 / 2372 环需求 / 76 地图 / 6240 点位；地图坐标拟合 + 地板吸附；OpenAI 兼容 tool calling 的 Agent 骨架；计划库 `files/plans.db`。
- 现状与原版差距已实机截图比对，明细见 `design.md`。

## Requirements

| # | 子任务 | 说明 |
|---|---|---|
| 1 | `ui-parity` | 浅色主题（原版配色）；首页 20 个功能大卡片网格；底部 5 tab 且可自定义；异刃页大立绘网格 + 属性/补正筛选；任务页四大类分流；怪物/设置页结构对齐 |
| 2 | `route-planning` | 地图逐步规划：只画最近传送点/地标 + 计划点 + 路径；分层地图正确归属；点位不出图 |
| 3 | `affinity-clarity` | 开环节点需求、获取途径、触发条件明确化，可从环节点跳到相关任务/采集/怪物 |
| 4 | `agent-integration` | 接入 OpenAI 兼容模型，暴露 App 内数据为 tools，支持路线/规划/开环问答，可把结果落成计划 |
| 5 | `icons-markers` | 补全异刃与物品图标；地图点位按类型用不同形状/图标标识，不只靠颜色 |
| 6 | `layered-maps` | 分层地图（室内/多层）切换与坐标归属验收 |

## Constraints

- **Clean-room**：`apk/`、`src/`（反编译产物）仅作对照，不打包进 APK、不直接复制原版资源文件。
- **不接入统计/隐私 SDK**：不复刻友盟+、AD_ID、更新检查、数据库增量下载。
- **密钥安全**：LLM endpoint / api key / model 只存模拟器 SharedPreferences，**禁止**写入 README、docs、Trellis 任务文件或任何提交物。
- **只改相关代码**：沿用现有架构（手写导航栈 + Compose），不引入新框架做大重构。
- 构建/验证以实机为准：每轮 `assembleDebug` → `adb install -r` → 截图留证。
- 根目录非 git 仓库，不涉及 commit/PR 流程。

## Acceptance Criteria

- [ ] 首页视觉与原版截图逐项一致或明确标注差异（20 卡片、浅色、5 tab）
- [ ] 底部 tab 可在设置中自定义（顺序/显隐）
- [ ] 任选一个任务计划：地图上只出现最近传送点、计划点与路径，点位 100% 落在地图内；分层地图可切换且点位跟随
- [ ] 异刃开环节点可看到「需求 / 获取途径 / 关联任务」，能一键跳转
- [ ] Agent 能通过 tools 读取任务/异刃/地图数据并产出可保存的计划
- [ ] 异刃与物品列表不再有占位空白图；地图点位不同类型形状可区分
- [ ] 全量回归：`plans.db` 中原有计划不丢失

## Known Limitations（记录在案）

- `route_connection` 表为空 → 没有真实路网，只能按最近邻排序，不能做图寻路。
- 采集（Collect）步骤自动落点率 32%，库里缺「物品 → 采集点」映射。
- 76 张图中 41 张可拟合「世界坐标 → 平面坐标」，其余多为室内小图、样本不足。
- 这些限制是否可由大模型缓解（而非消除）需在 `agent-integration` 里单独评估，不能默认「接了大模型就都能实现」。
