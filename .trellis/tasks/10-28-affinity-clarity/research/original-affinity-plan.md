# 原版 1.2.2 的「开环 → 规划」逻辑（反编译核对）

来源：`src/jadx/sources/cn/xenoblade2/wiki/p004ui/blade/BladeDetailScreensKt.java`、
`.../p004ui/cart/MaterialPlanningScreensKt.java`（本地反编译产物，不入库）。

## 页面结构

异刃详情 → `牵绊圆环` tab：

- 节点列表按 `blade_affinity_node.category` 分组，分类中文名：
  `blade_art` → 异刃武技，`field_skill` → 场景技能，其余 → 其他圆环节点。
- 点开节点后展示：
  - `等级效果`（effect）
  - `解锁条件`（requirement）
  - `最大等级：N`

## 「选哪一层」的交互（关键）

原版没有「一键生成整把异刃的规划」，而是把需求**加入购物车**：

1. 每个等级行有一个购物车图标，contentDescription 形如
   `切换第 3 层要求购物车` —— 说明「层」= 该节点的 Lv N。
2. 节点级还有 `切换节点要求购物车`，一次加入该节点全部等级的需求。
3. 已加入时图标换成「移出购物车」。
4. 购物车即素材规划清单：`ui/cart/MaterialPlanningScreens` 汇总这些需求，
   再反推材料/采集点（也就是我们要做成「计划」的东西）。

## 对我们的映射

| 原版 | 本项目 |
|---|---|
| 第 N 层要求加入购物车 | 等级行勾选（`AffinityLevel.id`） |
| 节点要求加入购物车 | 节点卡「加入」= 该节点所有未习得等级 |
| 购物车 / 素材规划 | `PlanStore` 里的一份开环计划 |
| 移出购物车 | 取消勾选 / 移出 |

## 与原版有意不同的地方

- 原版用全局购物车跨异刃累积；本项目按「一次生成一份计划」处理，选择态只在会话内。
- 原版「加入」后要再进素材规划页；本项目直接生成可勾选的步骤计划，少一层跳转。
